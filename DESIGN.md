# Halloween (IllFonic, 2026) → Minecraft

Приватный перенос геймплея *Halloween: The Game* в Minecraft. Только для личной игры с друзьями.

## Решения

| Тема | Решение |
|---|---|
| Оригинал | Halloween: The Game (IllFonic + Gun Interactive, 8 сентября 2026), асимметрия 1 на 4 |
| Платформа | Java Edition 26.2 + Fabric (loader 0.19.5, Fabric API 0.161.0+26.2), modid `halloween` |
| JDK | Temurin 25, лежит локально в `.jdk/` (в git не попадает) |
| Роли | Код пишет Claude. Пользователь принимает решения, проводит плейтесты, строит Haddonfield Heights в креативе |
| Аудитория | Приватно |
| Звуки | Сначала плейсхолдеры (ванильные файлы через `sounds.json`), финальные `.ogg` пользователь подкладывает в ресурс-пак |
| Числа | Механики как в оригинале, все числа в `config/halloween.json`, подгоняем по видео и плейтестам |
| Режим | Мультиплеер 1 на 4: Майкл всегда человек, недостающих жителей заменяют боты (позже) |
| Камера | У всех только вид от первого лица. Маска Майкла появляется только в Killer Sense |
| Здоровье | Своя полоска HP. Голод и реген отключены, ванильный HUD скрыт |
| Ваниль в матче | Adventure, всегда ночь, нет погоды и мобов |
| QTE захвата | Тайминг-полоска |
| Shape Jump | Жертвы не видят и не слышат Майкла. При выходе из рывка звучит стингер. У Майкла искажённая картинка |
| Голос | Simple Voice Chat, интеграция в следующих срезах |
| Карта | Срез 1 тестируем на полигоне `/hw arena`, полные карты потом |

## Срез 1 (текущий)

- **Killer Sense / Stalk**:
  - вид из прорезей маски, дыхание, точки фокуса на теле жертвы;
  - у каждой жертвы своя шкала Stalk: на 33% жертва ослаблена, на 66% помечена (подсвечивается за стенами), на 100% открываются особые добивания;
  - штраф за злоупотребление: с усталостью эффективность падает.
- **Bloodthirst**: общая шкала, уровни I/II/III. Уровни повышают урон, силу захвата, перезарядку и скорость Shape Jump.
- **Атака и захват.** QTE для жертвы — тайминг-полоска, её сложность растёт с силой захвата.
- **Добивания**: базовое из захвата и через окно (окно — только при Stalk 100% и стекле рядом).
- **Shape Jump**:
  - не работает на свету и в поле зрения жителей;
  - даёт невидимость, тишину и ускорение;
  - на выходе звучит стингер.
- **Свет**:
  - уличные фонари горят всегда;
  - в домах лампы (waxed copper bulb);
  - щиток питания — рычаг на железном блоке, гасит и включает лампы в радиусе.
- **Тест**: манекены (ванильный `minecraft:mannequin` с тегом `hw_victim`). За манекен QTE решается случайно. QTE со стороны жертвы проверяем на втором dev-клиенте.

### Управление

| Кто | Клавиша | Действие |
|---|---|---|
| Майкл | ЛКМ | Удар |
| Майкл | ПКМ по жертве | Захват |
| Майкл | R (удерживать) | Killer Sense |
| Майкл | V | Shape Jump |
| Жертва | Пробел | QTE |

### Команды (уровень оператора)

| Команда | Что делает |
|---|---|
| `/hw arena` | Строит полигон вокруг игрока |
| `/hw role <игрок> shape\|civilian\|none` | Назначает роль |
| `/hw mannequin` | Ставит манекен-жертву |
| `/hw bloodthirst <0-100>` | Задаёт шкалу Bloodthirst |
| `/hw reset` | Сбрасывает состояние матча |
| `/hw reload` | Перечитывает конфиг |

## Отложено

- Оглушение Майкла (вместе с лутом и оружием).
- Выходы: погреб, машина, полицейский фургон; телефоны и вызов полиции.
- NPC-горожане и очки.
- Боты-жители.
- Возвращение в матч помощником шерифа или Лумисом.
- Прогрессия.
- Полные карты: Heights, Town Center, Orange Grove Estates.
- Спорные механики (подтверждены одним источником): арест Майкла, Reality Tear, мини-игры погибших, задние ворота.
- Порядок следующих срезов решаем после плейтеста среза 1.
