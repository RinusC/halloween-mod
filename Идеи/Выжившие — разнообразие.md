# Выжившие — разнообразие геймплея

Вопрос пользователя 2026-10-24: «Как бы ты разнообразил геймплей за выжившего?» Сейчас: обыск → предметы для выхода → побег; бой (оружие, огнестрел, толчок), прятки (шкафчики, окна, двери), горожане, перки, мини-игры, события, помощник шерифа после смерти, опрокидывание в погоне. 12 героев различаются только сценой.

## Предложено
1. **Свой навык у каждого героя** (12): Лори — чует, где Майкл, на пару секунд; Томми — подбадривает (выносливость рядом); Линда — бегает тише; Бобби — чинит быстрее и т.п. Разные герои → разная игра.
2. **Сбит с ног, а не убит** — при 0 HP ползёшь/истекаешь кровью ~30 с; товарищ поднимает (аптечка быстрее). Командная игра, спасения, риск ради другого. Удар Майкла по лежачему — добивание.
3. **Метки для команды** — указать на предмет / Майкла / выход: видно всем выжившим несколько секунд (с голосом героя). Нет кооперации без голосового.
4. **Засада на Майкла** — общая цель: заманить к подготовленному месту (ловушка + свет + петарды) → долгое оглушение / шанс полиции арестовать. Переход от бегства к охоте.
5. **Случайные побочные задания в матче** — включить подстанцию (свет на улице, Майклу хуже прятаться), найти радио (слышно, где Майкл), спасти собаку (лает на Майкла). Разные матчи.
6. **Больше мест для пряток** — под кроватью, в машине, в мусорном баке, в погребе; у каждого свой риск.
7. **Обмен предметами** — бросить предмет товарищу.

## Решено (2026-10-24)
Сделаны: навыки героев (1), метки для команды (3), побочные задания — рация и собака (5). Не выбраны пока: сбит с ног (2), засада (4), больше пряток (6), обмен предметами (7); из заданий не сделаны подстанция и засада.
