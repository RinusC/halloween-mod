# ИИ-Майкл сквозь стены; фризы

Тема: [[Дизайн/Майкл|Майкл]]

- Выжившие, показанные Импульсом, для ИИ-Майкла теперь лишь наводка (он идёт туда), а не «вижу»: выслеживание и погоня — только когда видно глазами. Раньше он выслеживал сквозь стены тех, кого показал Импульс. «Импульс после 45 с без никого» считается от начала матча, не сразу на старте.
- Фризы по логам игры: (1) постройка изнанки — до 139 мс за тик → не больше 5 мс за тик; (2) прогулки горожан дома — до 8 попыток пути по 2500 узлов → 3 по 700, общий лимит поиска пути на тик 12000 → 6000 узлов (Townsfolk.HOME: 51 мс → 4 мс); (3) поиск щитков ботами (обход всего города) — раз за матч → раз на карту.
