# Баланс: двери и окна

Тема: [[Дизайн/Правки и прочее|Правки и прочее]]

| Механика | Правило |
|---|---|
| Запирание двери | Житель приседает и держит ПКМ на закрытой двери 1,5 с (открытую дверь сначала захлопывает) |
| Отпирание | Вдвое дольше, 3 с. Запертая дверь не открывается кликом |
| Майкл и запертая дверь | Выбивает ударами: лёгкий даёт 1 очко, тяжёлый 2, нужно 4. Дверь распахивается, замок сломан навсегда (до `/hw reset`) |
| Майкл в Поступи | Проходит сквозь любые двери. Выйти из Поступи внутри двери нельзя |
| Окно, медленно | ПКМ, 3 с. Целое стекло остаётся, без урона |
| Окно, быстро | Ctrl+ПКМ, 1 с. Стекло бьётся (остаются осколки), −1/5 макс. HP. Запрещено, если HP ≤ 1/5 |
| Разбитое окно | Лезть можно, но осколки режут при любом способе (−1/5 HP). Медленное перелезание не убивает, оставляет 1 HP |
| Майкл и окна | Не лазит. Расправа через окно тоже оставляет осколки |

Все числа лежат в конфиге: `lockTicks`, `unlockTicks`, `door*`, `vault*`. `/hw reset` отпирает двери и восстанавливает стёкла.
