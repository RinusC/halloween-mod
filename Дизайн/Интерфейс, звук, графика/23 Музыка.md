# Музыка

Тема: [[Дизайн/Интерфейс, звук, графика|Интерфейс, звук, графика]]

Саундтрек Halloween: The Game (файлы игрока), нарезан по таймкодам без перекодирования (`tools/split-music.sh`; сами файлы в git не попадают):
- **Stalking** — 3 композиции (0:00–9:15, 9:15–11:04, 11:04–конец).
- **Ambience** — 4 (0:00–3:15, 3:15–6:34, 6:34–9:47, 9:47–конец).
- **Being Stalked** — 3 (0:00–1:55, 1:55–3:51, 3:51–конец).
- **Michael Myers Proximity** — 4 (Close 0:00–1:05, Closer 1:05–2:11, Very Close 2:11–3:17, Closest 3:17–конец).

Кто что слышит (решает сервер раз в 0,25 с, клиент плавно сводит треки: 2,5 с между настроениями, 1,25 с между уровнями, 0,75 с в тишину):
- **Майкл:** Stalking по уровню кровожадности (1→1-я, 2→2-я, 3→3-я), пока только наблюдает; Proximity, пока гонится за тем, кто его видел, или держит кого-то.
- **Выжившие:** Ambience, когда спокойно (композиции идут по кругу); Being Stalked, когда Майкл ближе 24 блоков, но не гонится (не в Shape Jump); Proximity, когда он идёт на тебя ближе 16 блоков, а ты его видел за последние 5 с (держится ещё 4 с после).
- **Proximity по оглушению Майкла:** шкала < 34% → Close, < 67% → Closer, выше → Very Close, оглушён → Closest.
- **Убийство** (добивание в захвате, смертельный удар): вся музыка стихает, через ~3,5 с возвращается по условиям.
- Громкость — ползунок «Музыка» в настройках; ванильная музыка в матче молчит. Старая «тема приближения» убрана.
