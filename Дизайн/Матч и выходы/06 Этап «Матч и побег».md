# Этап «Матч и побег»

Тема: [[Дизайн/Матч и выходы|Матч и выходы]]

Решения пользователя (* — решено Claude, правится конфигом):

| Тема | Решение |
|---|---|
| Победа | По очкам. *Счёт Майкла сравнивается с суммой очков жителей |
| Таймер | 20 мин. *Конец: таймер или на стороне жителей не осталось никого живого и никого в ожидании |
| Выходы | Погреб, машина, полиция, ворота: по одному каждого типа в случайной точке. Каждый выпускает одного человека |
| Погреб | Болторезы (3 с) или ключ от замка (1,5 с). Майкл может захлопнуть открытый погреб |
| Машина | Деталь + ремкомплект + ключи (громкий запуск). Майкл может снять поставленную деталь, пока машина не заведена |
| Полиция | Звонок с телефона (10 с) → фургон через 2 мин, стоит 90 с. Майкл режет линию, тогда её нужно чинить ремкомплектом |
| Ворота | Открываются удержанием (8 с) только в последние 5 минут |
| Инвентарь | Рука + 3 кармана, листать колёсиком, при смерти всё выпадает |
| Предметы | Случайно по мебели (комоды, тумбочки, ящики, коробки…; на чужих картах — сундуки и бочки), обыск удержанием. *Пока выглядят как ванильные предметы со своими названиями |
| Оружие | Бита, карманный нож, газонные дротики (бросок). Огнестрел — следующий этап |
| Оглушение | Шкала у Майкла. Полная — падает на 4 с, отпускает жертву. Шкала спадает, оружие ломается |
| Возвращение | Сбежавшие и погибшие через 30 с становятся помощниками шерифа (дубинка + фонарик), **максимум 2 за игру**. Помощник отпирает и чинит, но не уходит через выходы. Повторно убитый — наблюдатель |
| Фонарик | ПКМ включает и выключает. Виден светящийся луч. Луч в лицо Майкла ослепляет его, пока луч на нём. Это настоящий свет: мешает Поступи |
| Карта | *Точки ставятся `/hw point add <тип>`, хранятся в мире. `/hw arena` расставляет всё сам. Телефон — свой блок |

### Как запускать

| Команда | Что делает |
|---|---|
| `/hw arena` | Строит полигон и расставляет все точки: погреба, машины, место фургона, ворота, телефоны, сундуки и бочки |
| `/hw start` | Запускает матч. Майкл выбирается случайно; если игрок один, он житель без Майкла (тренировка) |
| `/hw start <ник>` | Запускает матч с указанным Майклом |
| `/hw stop` | Останавливает матч |
| `/hw timer <сек>` | Задаёт оставшееся время |
| `/hw point add <тип>` | Добавляет точку на своей карте |
| `/hw point remove`, `list`, `clear <тип>` | Удаляет ближайшую точку, показывает или очищает точки |

Типы точек: `center`, `spawn_shape`, `spawn_civilian`, `spawn_deputy`, `cellar`, `car`, `police`, `gate`, `phone` (на телефоне должен стоять блок `halloween:phone`).
Погреб, машина и ворота строятся модом только в выбранной на матч точке (точка погреба — где стоишь, люк будет под ногами; ворота встают поперёк линии к `center`), после матча блоки возвращаются. Люк и калитку нельзя открыть рукой.

Действия «держать ПКМ» (обыск, выходы, телефон) после завершения требуют отпустить кнопку, чтобы случайно не уйти в побег.
