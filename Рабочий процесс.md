# Рабочий процесс

Как я (Claude) работаю над модом. Читать в начале каждой задачи.

## Порядок работы над задачей
1. Найти нужное: [[00 Карта проекта]] → тема в `Дизайн/` → нужный раздел; классы — в `Код/`. Большие файлы читать кусками.
2. Решения по дизайну спрашивать меню (AskUserQuestion), не списком текстом.
3. Сборка:
   ```
   export JAVA_HOME="$PWD/.jdk/jdk-25.0.4.1+1" && ./gradlew build -x test -q
   ```
4. **Перед копированием мода — отдельным вызовом** проверить, что игра не запущена (`Get-CimInstance Win32_Process`, java/javaw с `*Instances*Halloween*` в командной строке). Никогда не в одном пакете с копированием. Запущена — не копировать, сказать.
5. Копировать `build/libs/halloween-0.1.0.jar` в `C:\Users\RinusC\curseforge\minecraft\Instances\Halloween\mods\`.
6. Изменились настройки — поднять `HwConfig.VERSION`, дописать `migrate()` и перенести `config/halloween.json` инстанса (perl JSON::PP). Сейчас версия 18.
7. Раздел в `DESIGN.md` на русском, затем `perl tools/obsidian_export.pl D:/obsidian/obs_halloween/Halloween` (обновит `Дизайн/` и `Код/`), запись в [[Журнал]].
8. Коммит, в конце `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, затем `git push` (origin `RinusC/halloween-mod`, ветка master).
9. Отчёт пользователю — на русском.

## Тесты
- Пользователь не любит долгие тесты (игра зависает). Только короткие клиентские тесты, в фоне, с `timeout`: `HW_ONLY=<имя> ./gradlew runClientGameTest`. Скриншоты — `build/run/clientGameTest/screenshots/`.
- Сказал «сам проверю» — не тестировать.
- Имена тестов: michael, michaelmodel, michaelnav, raid (долгий), quake, items, demomodel, gunaim, lobby, arms и др. (`src/gametest/.../TestFilter`).

## Облачные сессии
Пользователь иногда работает в облачной сессии; изменения приходят веткой на GitHub (`master-…`). «Обнови мод» — `git fetch`, влить новое в master (если ветка не содержит наших коммитов — слиянием), собрать, поставить, push.

## Правила
- «Мод чисто для меня». Не распространять чужие ассеты; музыка игры не в git.
- Не читать файлы с учётными данными лаунчера (launcher_accounts.json).
- Скачивание — только с разрешения (имя файла, источник, размер).
- Ключи и пароли не писать в репозиторий и не повторять в чате.

## Подводные камни Minecraft 26.2
- Цветных полей в `Blocks` нет (`BLACK_WOOL` и т.п.): `Blocks.STAINED_GLASS_PANE.black()` или `MapPlan.b("black_wool")` по id.
- Многие исходники с CRLF: точечные правки — Edit или скрипт, сохраняющий концы строк.
- В аргументах bash на Windows `\t`/`\n` в строках не раскрываются — длинные правки писать файлом.
