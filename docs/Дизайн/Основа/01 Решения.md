# Решения

Тема: [[Дизайн/Основа|Основа]]

| Тема | Решение |
|---|---|
| Оригинал | Halloween: The Game (IllFonic + Gun Interactive, 8 сентября 2026), асимметрия 1 на 4 |
| Платформа | Java Edition 26.2 + Fabric (loader 0.19.5, Fabric API 0.161.0+26.2), modid `halloween` |
| JDK | Temurin 25, лежит локально в `.jdk/` (в git не попадает) |
| Роли | Код пишет Claude. Пользователь принимает решения, проводит плейтесты, строит Haddonfield Heights в креативе |
| Аудитория | Приватно |
| Звуки | Сначала плейсхолдеры (ванильные файлы через `sounds.json`), финальные `.ogg` пользователь подкладывает в ресурс-пак |
| Числа | Механики как в оригинале, все числа в `config/halloween.json`, подгоняем по видео и плейтестам |
| Режим | Мультиплеер 1 на 4: Майкл всегда человек, недостающих жителей заменяют боты |
| Камера | У всех только вид от первого лица. Маска Майкла появляется только в Killer Sense |
| Здоровье | Своя полоска HP. Голод и реген отключены, ванильный HUD скрыт |
| Ваниль в матче | Adventure, всегда ночь, нет погоды и мобов |
| QTE захвата | Тайминг-полоска |
| Shape Jump | Жертвы не видят и не слышат Майкла. При выходе из рывка звучит стингер. У Майкла искажённая картинка |
| Голос | Simple Voice Chat, интеграция в следующих срезах |
| Карта | Срез 1 тестируем на полигоне `/hw arena`, полные карты потом |
