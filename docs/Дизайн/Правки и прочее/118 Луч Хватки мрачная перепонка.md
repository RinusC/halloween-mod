# Луч Хватки: мрачная перепонка

Тема: [[Дизайн/Правки и прочее|Правки и прочее]]

(Заменено столпом света, см. ниже.) Летящая Хватка — перепонка шириной 1.5 блока (на блок шире прежней) и высотой 2.6, развёрнутая поперёк полёта (блок-дисплеи, поворачиваются вслед за направлением): снаружи тёмная дымчатая оболочка из чёрного стекла, сквозь неё просвечивает багровое свечение, по центру яркий алый шов, по краям тёмно-красные рёбра (блок нароста), внутри 5 алых жил, которые каждые 3 тика меняют место и длину (плавно). За ней тянется шлейф: большой дым, пепел, пыль из красного в чёрное, багровые споры; шёпот душ и гул долины душ. При броске — стон (заклинание вызывателя, заряд звукового удара, визг скалка) и вспышка тьмы у руки. Где она гаснет (стена, конец дальности, стан Векны) — клуб тьмы и шипение. Попадание считается по самой перепонке: по ширине поперёк полёта, на ладонь вглубь, по высоте. Пойманный выживший на 7 с погружается во тьму (эффект «Тьма»), снимается при разрыве. Конфиг v17: `vecnaGripWidth` 0.5 → 1.5.
